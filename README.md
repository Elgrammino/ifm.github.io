# IFM 2027 — пробная версия

Статическое приложение без установки зависимостей. Для публикации достаточно файлов из корня проекта; папка tests для сайта не нужна.

## Сценарий показа

1. Переключить день и тему в программе, открыть событие.
2. Добавить событие звёздочкой и найти его на главной.
3. Сохранить заметку в событии, открыть раздел заметок и выгрузить текст.
4. Открыть спикера и список его выступлений.
5. Демо управления: шесть быстрых нажатий по организаторам на главной, PIN 1234. Изменить время, отменить событие, добавить новость.

Программа и сведения об участниках взяты из исходного проекта и требуют подтверждения организаторов. Пульт работает только в этом браузере. PIN находится в исходнике и не является защитой для рабочего сервиса. Для реального запуска нужны серверная авторизация и общая база изменений.

Избранное и заметки хранятся в браузере. Старые данные переносятся при наличии сохранённой программы исходного IFM. При запрете хранения приложение предупреждает и использует память до закрытия вкладки.

## Проверка

`node --test tests/regression.cjs`

Проверки покрывают повреждённое хранилище, перенос заметок, неверные события, загрузку программы, избранное, карточки, ошибки сети и логику офлайн-кэша. Настоящий браузер и iPhone пока не проверены. Установка PWA и офлайн-режим требуют HTTPS или localhost и первого успешного открытия с сетью.

## Первый этап

- Ошибки localStorage больше не останавливают приложение; ключи привязаны к IFM и пути приложения.
- При ошибке загрузки открывается сохранённая программа или экран с кнопкой повтора.
- Проверяются время, длительность и общий сдвиг программы.
- Сдвиг и соответствующая новость сохраняются одной операцией.
- Кэш ограничен своим приложением и не удаляет кэши соседних проектов.
- Обработана ошибка service worker, освобождается временный адрес выгрузки.

Следующий этап: мобильная вёрстка, навигация назад, доступность карточек и проверка содержания программы вместе с Эдуардом.
