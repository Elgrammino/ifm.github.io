# МФИ 2027 — айдентика и язык интерфейса

Рабочие правила для форума и его мобильного помощника. Даты, залы, имена и темы берём из программы организаторов. Примеры времени ниже иллюстративные.

## 1. Название и знак

В русскоязычном интерфейсе пишем «МФИ 2027». При первом знакомстве можно раскрыть название «Международный форум иллюзионистов». IFM 2027 сохраняется в репозитории и на существующем адресе проекта.

Фирменные материалы: `assets/images/hero.jpg` для экрана и существующие `assets/icons/` для установки. Сохраняем силуэт, пропорции, надпись, цвета и узнаваемое свечение. Портреты организуем в `assets/participants/`; отсутствующий снимок можно заменить инициалами. Утверждённые материалы и исходники используем при подготовке новых размеров.

В текущих материалах знак растровый. Для пробы «логотип → стрелка → инструкция» сначала запрашиваем официальную векторную версию. Если её нет, сверяем контур по оригиналу, а свечение ведём отдельным слоем. Стрелка подчёркивает первый шаг инструкции в браузере. При запуске с иконки открывается «Сейчас».

## 3. Голос

### Brand Personality

| Черта | Как звучит |
|---|---|
| **Ясный** | В первом предложении то, что нужно человеку сейчас. |
| **Спокойный** | Изменение времени и проблемы со связью сообщаем коротко, с понятным следующим действием. |
| **Уважительный** | В инструкциях используем «Откройте», «Нажмите», «Добавьте». В названиях кнопок достаточно глагола. |

### Словарь

| Ситуация | Формулировка | Когда употребляем |
|---|---|---|
| Сейчас | «Идёт сейчас» | Есть текущее событие. Рядом название, время и имя спикера, если оно есть. |
| Дальше | «Дальше» | Следующее событие в программе. |
| Где | «Главный зал» | Подпись места, если оно известно. Отдельный экран навигации не предусмотрен. |
| Задержка | «Начало задерживается. Время уточняется» | Нового времени пока нет. |
| Прогноз | «Начало ориентировочно в 15:40» | Команда дала оценку. |
| Перенос | «Начало перенесено на 15:40» | Новое время подтверждено. |
| Отмена | «Событие отменено» | Команда подтвердила отмену. |
| Избранное | «В моё расписание» → «В расписании» | Состояние относится к событию в личном списке. |
| Сохранение | «Заметка сохранена на этом устройстве» | Только после успешной записи. |
| Программа офлайн | «Показана сохранённая программа» · «Обновить программу» | При открытии без сети. Время последней проверки показываем, если оно известно. |
| Версия IFM | «Доступна новая версия приложения» · «Обновить» | Новая сборка уже скачана и готова к применению. |
| Установка | «Добавьте МФИ 2027 на экран „Домой“» | Инструкция сразу видна только в браузере после QR. |

В тексте о переносе называем событие и новое время. В заметках и программе даты пишем как «20 января», время в формате «17:00–18:30» по времени площадки. Названия кнопок Safari и Chrome сверяем с фактическими меню устройств.

## 4. Проверка перед публикацией

- Знак и имя МФИ читаются. Тексты рядом не перекрывают знак.
- Статус понятен без цвета и звука. Заголовок, время и действие читаются на телефоне.
- «Обновить» относится к приложению, «Обновить программу» — к расписанию.
- Время и спикер взяты из утверждённых данных. Демо явно обозначено.
- Инструкция появляется в браузере. Запуск с иконки ведёт прямо на «Сейчас».
